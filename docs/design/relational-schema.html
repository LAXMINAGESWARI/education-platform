Integrity invariants

Database-enforced

Partial unique indexes & constraints
  • Email unique per institution
  • One role row per (user, role)
  • Student identifier unique per institution; one profile per user
  • At most one active academic period per institution
  • Unique period-grade, offering, topic/subtopic slug & sequence
  • One active grade enrollment per student/period
  • One active subject enrollment per student/offering
  • Unique material & quiz version numbers; one published material version
  • Answer keys 1:1 with question versions (isolated table)
  • Attempt uniqueness per (student, quiz_version, attempt_number)

Service-enforced

Transactional application rules
  • Subject enrollment offering shares grade enrollment’s period grade
  • Section (if set) belongs to enrollment’s period grade
  • Teaching assignments require teacher role
  • Quiz release requires published material + bindings
  • Published questions have ≥1 learning-outcome tag
  • Student APIs never join question_answer_keys
  • Deactivating a user revokes refresh sessions
