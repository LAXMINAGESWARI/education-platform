1. Originality

By signing, each person confirms that their contribution to CurioEd, and to this Submission Package, is their own work or the joint work of this group, except for the third-party components named below. The group is not submitting this project for assessment in another course under a different description of authorship. Where a person reused their own earlier notes, they can say so in the margin before signing.

2. Third-party software

The platform is built on software the group did not write. That software stays under its own licences. The lockfiles are the list: backend/uv.lock and frontend/package.json (and the frontend lockfile). Major pieces include Python, FastAPI, SQLAlchemy, PostgreSQL with pgvector, LangGraph, React, and Vite. The group claims the application code, the curriculum markdown it authored, the design notes, the tests, and this narrative. The group does not claim those libraries.

3. No real pupil records

The school called Al Noor International is synthetic. Names are drawn from lists in the generator. Marks and attendance are computed from seed 20260812. Nothing in the database is a record of a living child, and this package does not attach one. Demo accounts and the password demo1234 are local fixtures, documented in the repository README, for a database the group generates itself.

4. Confidentiality

Signing members will keep the following out of the upload and out of any public copy they do not intend to publish:

  • API keys, including any OPENROUTER_API_KEY. Keys live in uncommitted environment files.
  • Passwords other than the documented demo fixture.
  • Any pupil, parent, or staff record from a real school, should one ever be received. None is in this package.
  • Sponsor material the sponsor has not agreed to include. The minutes name Lakshmi's feedback in summary. They do not attach a sponsor document.

Results from the synthetic school will be described as results from the synthetic school. They will not be presented as measurements of a real cohort.

5. Drafting assistance

The narrative documents in this package (the report, this declaration, the form, the data note, the plain-language summary, the repository note, and the checklist) were drafted with Cursor, an AI coding assistant, from the group's repository: code, tests, and design notes. No AI system is an author. Each signatory is responsible for the accuracy of the text they sign. If a statement disagrees with the code, the code is the record and the text should be corrected before upload.
