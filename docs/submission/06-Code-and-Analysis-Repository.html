3. Run the analysis

  1. Install uv, Docker, and Node 18 or newer.
  2. From the repository root: docker compose up -d postgres. Wait until it is healthy.
  3. From backend/: uv run alembic upgrade head
  4. From backend/: uv run python -m education_platform.modules.synthetic.cli
  5. From backend/: uv run pytest tests/test_at_risk_engine.py tests/test_at_risk_api.py tests/test_at_risk_assistant_agreement.py
  6. Optional, the app itself: uv run uvicorn education_platform.main:app --reload --host 127.0.0.1 --port 8000, and from frontend/ npm run dev after copying .env.example to .env.

The engine tests include cases that do not need a database. The API and agreement tests need the migrated Postgres from step 2. CI on GitHub runs the full backend suite against a pgvector container.

4. What not to upload beside the link

  • backend/.env if it contains an API key.
  • The local upload directory of PDF blobs.
  • A dump of a database, even the synthetic one. The seed rebuilds it.
  • node_modules or the Python virtual environment.

A zip of the whole working tree would be a worse copy than the link: it goes stale, and it is easy to sweep a secret into it. If the LMS form will not accept a link without a file, upload this note (PDF and DOCX) and paste the link in the form field.
